🚀 IdeaVault

IdeaVault is a modern full-stack startup idea sharing platform where users can explore innovative ideas, share their own startup concepts, interact with others through comments, and manage their personal ideas and activities.

🌐 Live Website
🔗 Live Link: https://ideavault-client-website.vercel.app

✨ Features
🔐 Secure Authentication System with Email/Password & Google Login
💡 Users can Add, Update, and Delete their own startup ideas
💬 Interactive Comment System with Edit & Delete functionality
🛡️ Protected Private Routes using JWT Authentication
🔎 Advanced Search & Category Filter for exploring ideas easily
🌙 Fully Functional Dark & Light Theme Toggle
📱 Fully Responsive Design for Mobile, Tablet, and Desktop
⚡ Dynamic Route-based Page Titles using Next.js Metadata
🎨 Modern and Clean UI built with HeroUI and Tailwind CSS
📊 User Activity Tracking through My Interactions page
