## 📌 Project Overview

**IdeaVault** is a modern **full-stack startup idea sharing platform** where users can explore innovative startup ideas, share their own concepts, and interact with others through comments and engagement features.

The platform is built with a focus on:
- Clean and modern UI/UX
- Secure authentication system
- Full CRUD functionality
- Smooth user experience
- Scalable full-stack architecture

## ⚙️ Getting Started (Run Locally)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/ideavault.git

# 2. Go to project folder
cd ideavault

# 3. Install dependencies (frontend & backend)
npm install
cd client && npm install
cd ../server && npm install

# 4. Setup environment variables

MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Run project
npm run dev
```
